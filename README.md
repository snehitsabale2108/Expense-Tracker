# Expense-Tracker
Expense Tracker is a simple application that helps users record, manage, and track their daily expenses efficiently. It allows users to monitor spending, organize expenses, and maintain better financial control through an easy-to-use interface.

## Features

-  Add new expenses
-  View all expense records in tabular format
-  Calculate total amount spent
-  Delete specific expense entries
-  Automatically records current date
-  Stores data permanently in CSV file
-  Simple and user-friendly command-line interface
